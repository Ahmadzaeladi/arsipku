Design System · Enterprise SaaS

Bahasa visual ArsipKu

Sistem netral-first untuk manajemen arsip digital. Seluruh nilai visual ada di token CSS, komponen memakai atribut/ARIA untuk state-nya, dan halaman ini dimuat tanpa framework apa pun.

Prinsip

Empat keputusan yang membuat seluruh sistem ini konsisten — dan yang membatasi godaan dekorasi.

Netral dulu, warna berarti

Putih dan abu-abu mengerjakan 95% tampilan. Satu aksen indigo hanya untuk aksi utama dan status terpilih. Merah, hijau, kuning dipakai sebagai penanda, bukan sebagai latar besar.

Konten adalah hierarki

Nama berkas, ukuran, dan tanggal yang memimpin — bukan judul bagian. Judul halaman 24px adalah ukuran terbesar di halaman isi. Densitas baris 48px.

State lewat atribut

[aria-busy], [aria-invalid], [aria-selected], [aria-expanded], [disabled] — jadi tampilan tidak bisa tertinggal dari keadaan data.

Kedalaman nyaris nol

Hierarki dikerjakan border 1px dan ruang, bukan bayangan. Bayangan hanya muncul pada lapisan yang benar-benar melayang: menu, modal, toast. Tidak ada gradien, tidak ada blur.

Token warna

Klik swatch untuk menyalin nama variabel. Nilai dipakai apa adanya dari spesifikasi palette netral-first; tidak ada hex literal yang boleh muncul di berkas komponen.

Aksen & semantik

Hue tipe berkas

Sam persis dengan kelas yang dikirim src/Helpers.php:getFileMeta() (rose/blue/emerald/amber/purple/slate) supaya pemindahan bertahap tidak mengubah arti warna di aplikasi yang berjalan.

Rasio dihitung terhadap latar tempat pasangan itu benar-benar dipakai. WCAG 2.2 AA: teks biasa 4.5:1, teks besar 3:1, batas komponen UI 3:1.

Tipografi

Inter dengan fallback sistem. Baseline UI 14px, lantai absolut 11px. Tidak ada ukuran hero: judul halaman 24px adalah puncaknya, dan angka metrik memakai ukuran yang sama. Setiap peran punya kelas — bukan elemen yang ditentukan ukurannya.

Tombol

Satu tombol primer per tampilan. State dibaca dari pseudo-class dan atribut — arahkan kursor atau tekan Tab pada tiap tombol untuk melihat hover, focus, dan active.

Varian

primer · sekunder (default) · ghost · danger · danger-ghost · link

Ukuran & bentuk khusus

lg 40 · md 32 · sm 28 — lalu tombol ikon 32/28 dan state aria-pressed

Loading & disabled

aria-busy="true" menampilkan spinner tanpa mengubah lebar tombol; disabled memakai token --ark-text-disabled (4.0:1 pada subtle).

Tab & segmented control

Tab memindahkan area konten (garis bawah 2px accent). Segmented dipakai untuk sakelar tunggal seperti Daftar/Kisi, dan meniru #btn-view-list / #btn-view-grid yang sudah ada.

Bagian aktif segmented: latar putih + bayangan xs di atas rel abu — terbaca sebagai "terangkat" tanpa border tebal.

Modal

Header/body/footer dipisah border tipis; footer rata kanan, aksi destruktif di kiri. Fokus dipindah ke kontrol pertama, dikunci di dalam dialog, dan dikembalikan ke pemicu saat tertutup.

Toast notifikasi

Kartu putih dengan garis 3px penanda jenis — bukan kartu berwarna penuh. Region memakai aria-live="polite", kecuali kegagalan memakai assertive.

Toast muncul 6 detik, bisa ditutup, dan hilang lebih cepat saat kursor berada di atasnya.

Tooltip

Muncul saat hover dan :focus-visible, dengan tunda 120ms supaya tidak berkedip saat kursor melintas.

Isi data-ark-tooltip tidak boleh memuat instruksi wajib — gunakan untuk memperpendek label, bukan menggantikan.

Empty state penuh

Dipakai saat halaman benar-benar belum berisi data (workspace baru, Sampah kosong). Sudah tercakup di bagian Tabel untuk varian inline.

Belum ada berkas di workspace ini

Unggah berkas pertama, atau buat folder untuk memisahkan arsip berdasarkan bagian.

Spinner untuk aksi singkat, skeleton untuk muat awal (tata letak tidak melompat), progress bar saat durasi diketahui.

Aturan pakai

Enam aturan yang menjaga konsistensi saat halaman aplikasi ikut dipindahkan.

  • Nilai visual selalu lewat token. Tidak ada hex, px, atau ms literal di berkas komponen.
  • Satu .ark-btn--primary per tampilan; sisanya sekunder atau ghost.
  • State dari atribut/ARIA, bukan kelas baru. Kelas state hanya untuk hal yang tidak bisa diwakili ARIA (.is-selected, .is-dragover).
  • Semua kontrol form punya label terlihat; pesan validasi terikat aria-describedby dan tidak hanya berubah warna.
  • Kolom sekunder hilang bertahap lewat --hide-md / --hide-sm, bukan scroll horizontal pada mobile.
  • Teks minimum 11px, dan hanya untuk label UPPERCASE atau counter — isi terkecil 12px.
  • Ikon selalu berpasangan dengan teks atau aria-label; satu registry assets/js/icons.js, garis 1.75, currentColor — 18px nav, 16px toolbar/tabel, 28px empty state.
  • Aksi baris selalu terlihat (bukan hover-only) agar keyboard dan sentuh tidak buta.
  • Prioritas z-index hanya lewat token; tidak ada z-[9999] baru.
  • Gerak singkat dan fungsional: 80–240ms, tidak ada parallax atau gradien berjalan.
  • Komponen baru = berkas baru di assets/css/components/ + contoh di halaman ini + kontrak di docs/design-system.md.
  • --ark-text-tertiary dan border tipis tidak boleh membawa informasi wajib.
